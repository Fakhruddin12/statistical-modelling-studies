# Stochastic Epidemics on Contact Networks — LinkedIn Projects entry

## Project name
Stochastic Epidemics on Contact Networks

## Description
MSc team project implementing a stochastic SEIR model with households, persistent contacts and random transmission. Studied heterogeneous versus constant sociability through explicit state-transition probabilities.

Added a separately labelled Python reference experiment with 50 seeded replications for each of four scenarios. Checked population conservation, monotone susceptible/removed counts, network symmetry and valid infection probabilities across all 200 paths.

The analysis distinguishes simulation mechanisms from experimental design: random-only scenarios also change transmission intensity, so their differences do not isolate contact structure. These are conditional teaching simulations, not forecasts or public-health policy effects.
